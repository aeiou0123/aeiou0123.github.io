descriptive index / pilot

这是一套试测模型

当前版本把现实生活中的选择映射为连续描述性指数。它尚未使用代表性样本完成项目分析、因子验证或 IRT/MIRT 校准，因此不会把微小分差解释成精确测量。

资料层级

正式调查用于建立教育、家庭、就业和社会态度框架；现实行为资料帮助识别选择约束；青年社交媒体话语只用于发现情境和语言，不作为总体分布证据。

阶段等价

160 个概念题位中，112 题使用共同文本，48 题为高中、大学和初入职场提供等价场景。三个版本使用相同构念、方向和权重。

多重载荷

1–9 回答先转换为 -1 到 +1。同一道题可以同时对多个构念提供不同权重和方向的信息，再将加权均值映射到 0–100。

结果稳定度

稳定度只综合题目覆盖、跳过比例、构念内方向和回答区分度。它不等同于 Cronbach's alpha、测试重测信度或后验标准误。

隐私与密码

题库以 AES-GCM 密文发布，密码在浏览器中派生密钥。解密题库、答案和结果只保存在当前会话；关闭浏览器或主动锁定后清除。静态门禁不是服务器权限控制。

后续校准

获得试测样本后依次检查认知访谈、项目分布、项目-总分相关、EFA/CFA、MIRT/IRT、阶段测量等值性和结果叙事的稳健性。

使用边界
